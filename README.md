# Modern Login Page UI Design

A modern and responsive login page design built with HTML and CSS. This project showcases a clean user interface with a centered login card, polished form controls, and a subtle animated background.

## Features
- Modern and attractive layout
- Responsive design for different screen sizes
- Clean login form with username and password fields
- Stylish buttons and hover effects
- Simple and lightweight structure

## Project Structure

```text
Modern-Login-Page-Ui-Design/
├── LoginPage/
│   ├── index.html
│   ├── style.css
│   └── low-poly-grid-haikei.svg
└── README.md
```

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- SVG background image

## How to Run
1. Open the project folder.
2. Open the file LoginPage/index.html in your browser.
3. You will see the login page UI.

## Preview
The page includes:
- a centered login card
- a title and subtitle
- username and password input fields
- a forgot password link
- a login button
